# Black Rose Tattoo & Piercing

A professional tattoo and piercing shop website built with React, TypeScript, and Express.

## Features

- **Professional Portfolio**: Showcase of tattoo and piercing work
- **Artist Profiles**: Meet our talented artists (Renzo, Big Head, J.R, Lopez)
- **Online Booking**: Schedule appointments for tattoos and piercings
- **Customer Reviews**: Real Google reviews from satisfied clients
- **Gothic Design**: Dark red aesthetic with Cinzel fonts
- **Mobile Responsive**: Optimized for all devices

## Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion
- **Backend**: Express, Node.js
- **Database**: SQLite (with PostgreSQL support)
- **Deployment**: Render.com
- **Routing**: Wouter
- **Forms**: React Hook Form with Zod validation

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Deployment

This app is configured for deployment on Render.com with:

- Automatic SQLite to PostgreSQL migration support
- Native dependency handling for better-sqlite3
- JSON storage fallback for serverless environments
- Comprehensive error handling and logging
